Nobuaki Masaki's first task after joining the DataSquad was a visualization of the international student body for the Office of International and Intercultural Life. It overlapped with a data visualization course he was taking, so he tried D3, a JavaScript library, though he was more used to R.

He began from an open source JavaScript file that color-codes the population of each country on a world map, and formatted the international student data into a CSV file for it. The project let him use coursework on a real request.
