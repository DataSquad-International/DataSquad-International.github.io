I have been working on developing a website that helps alums tag their fellow classmates in the pictures extracted
from the College archives. The website will be used at Reunion events to reduce the manual labor required in labeling and
filtering pictures, and it is designed to be as user-friendly and efficient as possible. For this project, I used React
and node.js to set up the frontend and backend parts and connect them to the existing databases.
